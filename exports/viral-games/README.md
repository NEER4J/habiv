# Habiv browser game pack

This folder contains 50 self-contained browser games. Each numbered folder has the source HTML, the local Habiv bridge SDK, `habiv.json` metadata, `metadata.json`, and thumbnail assets. Each matching ZIP contains the uploadable `index.html`, `habiv.json`, and `habiv-bridge.js`, so the Habiv upload form can auto-fill the game details and the game can use the SDK immediately. Add the matching `thumbnail.png` separately when uploading.

All games are touch-friendly, keyboard-friendly, offline-safe, and use no external dependencies.
